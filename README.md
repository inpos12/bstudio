# 🥟 B Studio (클론코딩)

## 📌 프로젝트 소개
웹 개발을 배우고 가장 처음 진행한 첫 번째 프로젝트입니다.
기초적인 웹 구조를 이해하고, 실제 사이트를 참고하여 클론 코딩을 통해 제작했습니다.
Bootstrap을 활용하여 반응형 레이아웃을 구축했습니다.
 
---

## 🛠️ 기술 스택

### ✅ Front-end
- Html  
- CSS  
- Javascript
- Bootstrap

---

## 🧩 주요 구현 내용

- **Bootstrap**을 활용해 다양한 해상도에 대응하는 반응형 레이아웃을 구현했습니다.


## ✨ 한 줄 요약

클론 코딩을 통해 웹의 구조를 이해하고, 반응형 웹 제작 경험을 쌓을 수 있었습니다.
